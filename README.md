# Tribal Trouble: Resurrected — русификатор

Полный русский перевод [Tribal Trouble: Resurrected](https://store.steampowered.com/app/3945720/) (Steam): меню, настройки, обучение, обе кампании (викинги и туземцы), сетевая игра. Всего 1233 строки.

## Установка

1. Скачай `TribalTrouble_RUS.exe` из [Releases](../../releases/latest).
2. Запусти и нажми **Установить русификатор**. Папка игры находится сама.
3. В игре открой **Options → Language → Русский** и перезапусти игру.

Windows может предупредить о неизвестном издателе — exe не подписан.

Обновление игры в Steam стирает перевод. Тогда запусти exe ещё раз и нажми **Переустановить русификатор**.

## Как это устроено

Своих языков игра подключать не умеет, поэтому установщик правит `app\tt-*.jar`:

- в списке языков датский меняется на русский: в `Languages.class` заменяются две строковые константы;
- заголовки переводятся на шрифт Inter Tight, потому что в Impact нет кириллицы;
- в jar добавляются файлы `*_ru.properties` из папки `translations`.

Перед правкой рядом сохраняется копия оригинала `tt-*.jar.ru-backup`. Кнопка **Удалить русификатор** возвращает её на место.

## Сборка

Запусти `build.ps1`: он собирает exe штатным `csc.exe` из .NET Framework, ставить ничего не нужно.
